# Project Evil

A single-player-first Resident Evil 4 (2005) inspired campaign mod for Project Zomboid, with a future co-op-compatible architecture.

## First chapter in development: The Missing Village
- Follow Leon Kennedy in an original story, not a retelling of Resident Evil 4.
- Investigate vanished residents, prepare for nightfall, and survive the return of infected villagers.
- Use Project Zomboid's survival, inventory, crafting, and base-defense systems.
- Save mission progression in the world save.

## Important scope notes
- Project Zomboid is the host game for Melty compatibility.
- Resident Evil 4 (2005) is not bundled; copyrighted game assets must come from the player's own installation and are not included in this repository.
- The first slice is a prototype until it has been launched and verified in the target Project Zomboid build and Melty.

## Development
The mod targets Project Zomboid Build 42's versioned mod structure. See `docs/IMPLEMENTATION.md` for current scope and testing requirements.
